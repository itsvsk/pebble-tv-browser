# Pebble glass UI

The current interface follows the Stitch project **Pebble - new glass UI** (`6340661125653276849`). Its five screens map to the Android TV app as follows:

| Stitch screen | Native screen |
| --- | --- |
| Home Screen | Search, speed dials, featured portals |
| Browser View with HUD | Full-page WebView with a floating bottom toolbar |
| Tab Manager | Horizontal, remote-navigable tab carousel |
| Library | Bookmarks grid with a History entry |
| Downloads Manager | Frosted download drawer with working type filters |

The shared shell provides top navigation, a TV status area, and remote key hints. The palette uses obsidian surfaces and electric cyan focus rings. Plus Jakarta Sans is bundled under its SIL Open Font License in `core/design/licenses/`.

Stitch contains illustrative sample sites, media, and storage figures. The app uses real bookmarks, tabs, history, and downloads instead. Its featured portal cards open live sites. Tab and bookmark cards use favicons and atmospheric previews because the current data model does not store page screenshots.
